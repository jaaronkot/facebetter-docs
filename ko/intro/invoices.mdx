---

결제는 Stripe에서 처리되며, 결제가 성공할 때마다 인보이스가 발급됩니다. 인보이스에는 고객 정보에 저장된 청구 정보가 표시됩니다.

## 인보이스에 표시되는 내용

- **이름**: 입력한 성명 또는 회사 법인명
- **청구지 주소**: 결제 시 또는 결제 포털에서 입력한 주소
- **세금 ID**: 등록한 경우 기업 세금 ID

콘솔 **Billing** 페이지에서 모든 인보이스를 보고 다운로드할 수 있습니다.

## 결제 시 입력

1. Stripe 결제 페이지에서 **청구 정보**를 열고 회사 법인명과 전체 청구지 주소를 입력합니다. 청구 국가는 회사 등록 국가와 일치해야 합니다.
2. 해당 국가가 기업 세금 ID를 지원하면 **회사 명의로 구매합니다**를 선택하고 법인명과 세금 ID를 입력합니다.
3. 결제를 완료합니다. 입력한 정보는 저장되어 이번 및 이후 인보이스에 표시됩니다.

Alipay, WeChat Pay, 평생 라이선스 같은 일회성 결제에도 같은 항목이 적용됩니다. 주소는 항상 수집되고, 세금 ID 양식은 지원 국가에서만 표시됩니다.

결제 시 세금 ID 수집은 튀르키예, EU 회원국, 영국, 아랍에미리트, 호주, 캐나다 등 많은 국가에서 지원됩니다. 양식은 선택한 청구 국가에 따라 자동으로 표시됩니다.

<Note>
세금 ID 필드는 **기업** 세금 ID 전용입니다. 튀르키예는 TR TIN, EU 국가는 VAT 번호를 입력합니다.
</Note>

## 나중에 추가하거나 변경

결제 시 청구 국가에 세금 ID 양식이 표시되지 않는 경우(예: 중국) 결제 후 추가할 수 있습니다.

1. 콘솔 **Billing** 페이지를 엽니다.
2. **구독 관리**를 누른 뒤 청구 정보 항목을 선택해 Stripe 결제 포털을 엽니다.
3. **청구 정보**에서 이름, 청구지 주소, 세금 ID를 변경합니다. 세금 ID를 추가하려면 유형을 선택하고 번호를 입력한 뒤 저장합니다. 여러 개가 필요하면 **증명 추가**를 누릅니다.

<Warning>
변경 사항은 저장 후 발급되는 인보이스에만 적용됩니다. 이미 발급된 인보이스는 최종본이며 수정할 수 없습니다. 첫 결제 전에 정보를 확인하세요.
</Warning>

발급된 인보이스를 수정해야 하면 지원팀에 문의하세요.
